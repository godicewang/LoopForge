# Legacy Causal Strategy Gate

Status: **F-05 legacy source/controller and package receipts present; production causal-descriptor cutover pending**

Recorded: `2026-08-11T05:10:41Z`

## Defect confirmed

The legacy Graph replacement gate normalized the proposed objective and
verification sentences, then treated any wording difference as a materially
different strategy. A new node ID plus paraphrased prose could therefore
recreate an exhausted causal route without changing its tools, evidence route,
or mutation surface. The final-audit characterization test also ratified this
behavior by accepting a second read-only artifact audit solely because its
objective and verification nouns changed.

This was a direct convergence defect, not a prompt-quality issue. Strategy
retirement could be bypassed by lexical novelty generated by the same reviewer
that requested another attempt.

## Repair

`GraphNodeStrategyEscalationPolicy.isMateriallyDifferent` no longer grants
novelty from the node ID, title, objective, verification wording, or ordering
noise in declared scopes. The legacy checkpoint can authorize one replacement
only when its mechanically observable causal topology changes:

- read-only versus writable execution is an explicit axis;
- writable execution requires at least one exact repository-relative scope;
- scopes are slash-normalized, wildcard-normalized, deduplicated, and sorted;
- ordering, duplicate entries, `./`, and trailing recursive wildcard noise are
  causally inert;
- missing, narrative, absolute, escaping, and control-character scopes fail
  closed;
- equivalent read-only routes remain the same strategy even when every prose
  field and the node ID changes;
- a genuinely different normalized mutation-surface set may receive one
  bounded replacement attempt, subject to the existing scope and retirement
  gates.

The final-audit regression was corrected: a differently worded read-only audit
of the same route is now rejected instead of being presented as a safe new
strategy.

## Adversarial verification

- new ID, title, objective, and verification prose with the same scope reject;
- equivalent wildcard, `./`, duplicate, and reordered scope spellings reject;
- absolute, parent-escaping, and narrative scopes reject;
- read-only-to-read-only paraphrases cannot revive retired work;
- read-only-to-writer and normalized mutation-surface changes remain eligible;
- existing graph scheduling, dependency rewiring, final repair, transactional
  mutation, visual gating, recovery, and runtime supervision tests still pass.
